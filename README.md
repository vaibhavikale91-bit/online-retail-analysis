# online-retail-analysis
End-to-end data analysis project using Python and SQL to analyze online retail sales, customer behavior, revenue trends, and RFM segmentation.
# Online Retail Data Analysis

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- MySQL
- Jupyter Notebook

## Project Description
This project analyzes online retail sales data to understand
customer behavior, revenue trends, and customer segmentation.

## Key Analysis
- Monthly revenue trends
- Country-wise sales analysis
- RFM customer segmentation

## How to Run
1. Import CSV into MySQL
2. Run SQL queries from `sql/analysis.sql`
3. Open Jupyter notebook and run analysis
